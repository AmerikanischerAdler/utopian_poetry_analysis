# Utopian Poetry Analyzer

## Description

A tool for analyzing utopian poetry. Featuring "Utopia" by Wislawa Szymborska

### Stack

| Type  | Structure | Style | Elements   | Routes  |
| :---: | :-------: | :---: | :--------: | :-----: |
| Flask | HTML5     | CSS3  | JavaScript | Python3 |

## Installation

1. Open Terminal and Clone Repository:

```bash
git clone https://github.com/AmerikanischerAdler/utopian_poetry_analyzer
```

2. Install Python:

If python3 is not installed on your machine, run:

**MacOS:**

```bash
brew update 
brew install python3
``` 

**TIP**: For MacOS, be sure that homebrew is installed on your machine. If not,
visit [HomeBrew](https://brew.sh) to install.

3. Set Up Virtual Environment:

Make sure you're in the utopian_poetry_analyzer directory

```bash
cd utopian_poetry_analyzer
```

Create virtual environment

```bash
pip3 install virtualenv
python3 -m venv venv
source venv/bin/activate
```

4. Install Dependencies:

```bash
pip install -r requirements.txt
```

5. Terminate Virtual Environment:

```bash
deactivate
```

## Usage

1. Open Terminal

2. Navigate to utopian_poetry_analyzer Directory:

```bash
cd utopian_poetry_analyzer
```

3. Start Virtual Environment

```bash
source venv/bin/activate
```

**TIP**: To terminate your virtual environment, run:

```bash
deactivate
```

4. Start Flask App:

*This will spin up a local backend server*

```bash
python3 app.py
```

**TIP**: To terminate your local server, press CTRL-C

5. Open Web Browser to New Tab or Window

6. Enter Server Address in Search Bar:

You may be able to simply click this link: http://127.0.0.1:5000/
